Currently in the prototyping phase. The app.py contains scratchpad code (literally) and UI experiments for the volleyball team system. Moving toward a structured multi-page architecture soon.

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
